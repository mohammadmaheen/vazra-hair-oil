- **🏛️ High-Definition Hero Showcase**: Seamlessly integrated, razor-sharp authentic bottle artwork framed in architectural arches and stone pedestals with natural lighting and soft contact shadows.
- **🌿 Botanical Science & Ingredients Carousel**: 
  - Dynamic 3D-feel rotating card showcase highlighting core herbs.
  - Scientific botanical nomenclature prioritised alongside traditional Ayurvedic naming (*Eclipta prostrata*, *Emblica officinalis*, *Bacopa monnieri*, *Hibiscus rosa-sinensis*, *Sesamum indicum*, etc.).
- **✨ Visual Transformation**: Interactive before-and-after comparison slider and authentic customer transformation stories.
- **🧘 The 4-Step Hair Care Ritual**: Step-by-step visual guide on warm-oil dispensing, crown massage, deep overnight absorption, and natural glow rinse.
- **📱 Responsive & Accessible**: Optimized for mobile, tablet, and widescreen displays with fluid touch interactions and micro-animations.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18.0.0 or higher recommended)
- `npm` or `yarn`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mohammadmaheen/vazra-hair-oil.git
   cd vazra-hair-oil
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
